RUTA EXPRESS - COMERCIAL MÓVIL PRO

Subir todos los archivos de esta carpeta a la raíz del repositorio de GitHub Pages. La página inicial es index.html.

Incluye CLIENTES v2.6 y COTIZACIONES v3.22 sin modificaciones internas. El menú carga cada módulo por separado, compartiendo almacenamiento local en el mismo dominio.

ATENCIÓN: los registros se guardan localmente en el navegador/dispositivo, NO se sincronizan automáticamente entre teléfonos ni se respaldan en la nube. Antes de cambiar de navegador o borrar datos, exportar los registros desde el módulo si dispone de esa opción.

La función de dictado y compartir por WhatsApp debe probarse en Chrome Android bajo HTTPS.

Instalación Android: abrir la URL publicada en Chrome, menú de tres puntos, Agregar a pantalla principal o Instalar aplicación.
